# Aurevia Ventures

A static, multi-page venture capital website built around the Asymmetric Editorial layout and Dark Luxury visual direction.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173/`. Routes use folder-based `index.html` files so links remain clean.

## Before launch

- Replace the example domain in canonical tags, sitemap and robots with the production domain.
- Replace the contact email if needed.
- Add approved team, portfolio and regulatory copy.
- Add production analytics only after updating the Cookie Policy and consent behavior.
